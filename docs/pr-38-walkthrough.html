04 · PDF reliability

Download once, trim only when needed.

All PDF controls are in src/pdf_preprocessor.py and can be tuned in the pdf: section of config.yaml.

1

Stream the download

Chunked requests use separate connect/read timeouts, retry transient HTTP failures, back off exponentially, and resume partial responses with a Range header.

2

Check the original byte size

If the PDF is under 15 MiB, both providers get the complete document path: Gemini receives the complete PDF and DeepSeek extracts the complete text.

3

Find the paper body

For oversized files, the extractor recognizes configurable headings such as References, Bibliography, and Works Cited, then stops before that section when possible.

4

Apply the hard fallback

If the body still exceeds the byte cap, retain at most 12 pages, then drop trailing pages backward until the generated PDF fits. A single oversized first page is retained as the smallest useful input.

05 · Review fix

Provider-only overrides now stay compatible.

The latest review caught a subtle configuration collision: a committed DeepSeek model could leak into a one-off Gemini run.

Before
config.yaml:
  provider: deepseek
  model: deepseek-v4-flash

--provider gemini
→ Gemini client + DeepSeek model ID
→ request can fail
After
--provider gemini
→ gemini-flash-latest

--provider gemini \
  --model gemini-2.5-flash
→ explicit model wins
Resolution rule: an explicit model override wins; otherwise the committed model is used only when its configured provider matches the selected provider. A mismatch falls back to that provider’s default.
