title: From Black-Box Binaries to Working Code&#58; MindForge Teaches Small AI Models
  to Build Software From Scratch
---



Ask an AI coding agent to patch a bug in a large codebase and it may shine. Ask it to build a complete program from nothing—working only from a compiled executable and its documentation—and even the largest frontier models falter. On the ProgramBench benchmark, which contains 200 real-world command-line tools, frontier models fully resolve fewer than 1% of tasks.

Now researchers have shown that a 27-billion-parameter model can get surprisingly close to that frontier, not by scaling up, but by learning the *whole life cycle* of software development from an AI teacher. The system, called MindForge, distills long, end-to-end programming trajectories into a small model—and the results are dramatic.

MindForge works by converting open-source CLI programs into "source-free" training environments. The agent sees only a compiled reference executable and sanitized documentation—never the original source code. It must infer what the program does, design an architecture, implement it, debug failures, write tests, and iterate until it produces a passing build. Think of it as asking someone to recreate a Swiss Army knife by examining a sealed one through a glass box.

The research team built 562 such environments from programs in Go, Rust, C, C++, Swift, and TypeScript. Then they used GLM-5.2, a powerful frontier teacher agent, to collect 1,001 complete development trajectories. Those trajectories are long—averaging 181 turns and up to 272,000 tokens—and cover specification exploration, design, bug localization, and refinement.

Merely copying those trajectories worked. Fine-tuning Qwen3.6-27B on the distilled data raised its average ProgramBench pass rate from 37.98% to 49.51%. That beats DeepSeek V4 Pro (47.80%) and approaches Claude Opus 4.7 (51.38%). On one instance, reproducing the popular terminal tool `cmatrix`, the small model achieved a perfect 100% score—a result previously achieved only by GPT-5.5 in its highest reasoning mode.

The gains extend beyond ProgramBench. MindForge-27B improved its base model's score on RepoZero C2Rust from 47.00% to 78.00%, boosted DeepSWE from 1.76% to 15.92%, and added roughly five points to SWE-bench Verified, Pro, and Multilingual.

Perhaps most revealing is *how* the model behaves. After fine-tuning, it roughly doubles its turns and tool calls per task, while its per-command failure rate actually drops. It is also far more likely to convert a failed command into an immediate code edit: the rate jumps from 31.8% to 48.8%. In one 830-turn, 209.5-million-token ProgramBench run, the small model kept working productively where its base model would have stalled or looped.

The MindForge approach matters because it avoids source-level contamination—agents never see the code they are asked to recreate—and it turns abundant open-source repositories into scalable training signal. For building capable AI software engineers, the recipe may be simple: don't just teach a model to patch code, teach it to build entire programs from scratch.
